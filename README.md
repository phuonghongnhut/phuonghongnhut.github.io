# 📓 Hồng Nhựt

Blog cá nhân ghi lại các kiến thức trong quá trình học tập.

📝 Bài viết nằm trong `src/content/docs/`.

## 🚀 Chạy local

```bash
npm install
npm run dev
```

🌐 Trang chạy tại `http://localhost:4321`.
