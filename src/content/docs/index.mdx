This site is a short manual. The contents are listed on the left. Each page is one Markdown file.

## Run the site

From the project folder:

```sh
npm run dev
```

The terminal prints a local URL. Open it to read the site. Saving a file refreshes the page.

## Add a page

Create a file under `src/content/docs/`. The path is the URL, so `src/content/docs/guides/pages.md` is served at `/guides/pages/`.

Add a line to the `sidebar` list in `astro.config.mjs` when the page should appear in the contents.
