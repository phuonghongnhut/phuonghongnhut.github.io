Import components from `@astrojs/starlight/components` inside an `.mdx` file.

## Tabs

`<Tabs>` and `<TabItem>` switch between npm, pnpm, and Yarn on the Getting Started page. Give matching groups the same `syncKey` so they stay on the same package manager.

## Asides

`<Aside type="tip">` is the purple box with a rocket icon. Other types are `note`, `caution`, and `danger`.

## Cards

`<Card>` and `<CardGrid>` lay out short links in a grid. Use them when a page is a menu of next steps rather than a long guide.
