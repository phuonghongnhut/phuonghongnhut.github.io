---
title: Authoring Content in Markdown
description: Write pages with Markdown and MDX.
---

Pages can be `.md` or `.mdx`. Use Markdown for prose. Use MDX when a page needs a Starlight component such as tabs.

## Headings

`##` and `###` headings show up in the “On this page” list on the right. Keep the page title in frontmatter, and start the body at heading level 2.

## Callouts

A tip renders as a highlighted box:

```md
:::tip
Leave the dev server running while you edit.
:::
```

Set a custom label with `:::tip[See it in action]`.
