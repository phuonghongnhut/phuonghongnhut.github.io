---
title: Frontmatter Reference
description: Fields at the top of a docs page.
---

Frontmatter sits between the `---` lines at the top of a Markdown or MDX file.

## title

Required. Rendered as the page heading.

## description

Required. Used for the page summary and metadata.

## draft

Optional. Set `draft: true` to hide the page from production builds.

## template

Optional. `splash` replaces the docs sidebar with a landing hero. This site’s home page leaves it unset so the sidebar stays visible.
